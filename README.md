# Telegram Bot: Text Analysis and Translation

Этот проект — небольшой Telegram-бот, который:
- принимает текст от пользователя;
- переводит сообщения между языками;
- хранит историю сообщений по пользователю;
- отвечает автоматически на часто задаваемые вопросы.

## Что добавлено
- словарь `qwestions` с готовыми ответами;
- условная проверка по ключам словаря;
- резервный ответ через `get_answer()`.

## Запуск
1. Убедитесь, что установлен пакет `pyTelegramBotAPI` и `translate`.
2. В файле `config.py` укажите корректный токен бота.
3. Запустите:
   python main.py

## Пример
- сообщение: `как тебя зовут`
- ответ: `Я супер-крутой-бот и мое предназначение — помогать тебе!`
